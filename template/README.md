本目录保留六个游戏站模板。选择模板时，从下列源码目录开始：

| 目录 | 模板项目 |
| --- | --- |
| [temp1_based_vvultimatum.net](temp1_based_vvultimatum.net/) | Eclipse Requiem Wiki |
| [temp2_based_farevergame.wiki](temp2_based_farevergame.wiki/) | Aetherfall Archive |
| [temp3_based_gamblewithyourfriends.net](temp3_based_gamblewithyourfriends.net/) | Neon Stakes Guide |
| [temp4_based_miniwars.art](temp4_based_miniwars.art/) | Frontier Command Codex |

| [temp6_based_theskinstapler.com](temp6_based_theskinstapler.com/) | Midnight Evidence Wiki |
