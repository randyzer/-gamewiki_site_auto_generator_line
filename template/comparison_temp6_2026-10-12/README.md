# 三版 The Skin Stapler 模板对比

日期：2026-10-12。此次仅评估，没有修改三份应用源码或锁文件。原工作目录已经更名为 temp6_origin，依据 README、配置和内容结构识别为教练原始版。

结论：长期多语言游戏攻略站底座推荐 Prompt 3.0；严格还原原站外观与指定页面内容，教练原始版最优。Prompt 1.0 保留了较完整的 Legal 内容和静态生成结构，但综合扩展能力已被 3.0 超过。

## 本次验证

- 三版类型检查与生产构建均通过。原始版 4 项测试、3.0 的 5 项测试通过；1.0 没有单元测试命令，执行了其路由检查。
- 原始版 15 个语言路由逐页 HTTP 200，html lang 正确；未知攻略 404；/en 仍返回 200。
- 1.0：41 内容路由、923 条链接与锚点检查通过。
- 3.0：205 页、15 个未知路径、8 项重定向、235 个不同内部链接地址、6 个图片资源检查通过；canonical origin/path、hreflang 与本地化链接通过。链接数字采用各项目脚本不同统计口径，不能直接作为质量排名。
- 3.0 浏览器交互脚本通过：八项移动菜单、搜索推荐和方向键 / Enter、Escape 与焦点恢复、五语切换保留文章及锚点。5 语 × 3 类型 × 2 视口，共 30 组没有横向溢出。
- 另在同一 Tabbit 浏览器实测原站及三版：4 站 × 3 类型 × 2 视口，共 24 组；所有图片加载成功，没有主内容、导航或页脚可见元素越界，也没有记录到 pageerror。
- 1440px 实际内容宽 1425px，390px 实际内容宽 375px，均为桌面浏览器滚动条占 15px。此次不混用以前隐藏滚动条的 390px iframe 结果。没有实体手机测试或 Lighthouse 性能测试。

## 3.0 的主要进步

1. 结合了原始版的五语能力与 1.0 的内容自动发现机制，避免不同语言重复页面结构、手动同步路由与搜索清单。
2. 核心导航、MDX 正文、关联文章及页脚均为本地路由，非英文阅读不会因核心入口跳回对标站。
3. canonical 与 hreflang 实际输出正确，英文前缀地址永久重定向，语言切换保留文章和首页锚点。
4. 关联文章从 MDX related 元数据及分类产生，搜索支持推荐和键盘选择；内容元数据验证更严格。

## 3.0 尚需处理的事项

1. 175 个 MDX 不等于 175 篇完整攻略。每种非英文语言中，34/35 篇辅助正文不足 1000 字符（包含 Markdown 标记），中文辅助正文中位数约 282 字符；抽样发现重复的观察提示及虚构项目说明。开发者详情有长文，其余需要按真实游戏补充有用内容。
2. Legal 页从 1.0 的四篇独立内容变成每页一段说明。需要恢复共享 Legal 模板及合适正文。源码：[3.0 Legal 渲染](/Users/randyz/work/coding/hot_words_web/template/temp6_based_theskinstapler.com_V3.0/app/[[...segments]]/page.tsx:57)。
3. 3.0 核心页面当前采用 SSR。纯内容站可以考虑按 locale 静态生成，并用配置的正式域名生成 canonical，降低对请求头和运行时服务的依赖。这是部署与缓存取舍，此次未测延迟，不能声称其实际速度慢于另外两版。
4. 默认 noindex,follow 尚未开放收录；本次未发现自动 sitemap 路由。正式发站前需配置域名、内容和索引策略。
5. 它仍改写了品牌、图片、商店 / Discord / 视频 / Demo 等内容。如果验收标准是原站原样复刻，原始版更符合要求。

## 对 Prompt 的结论边界

本次评价的是三份实际产物，没有读取三份 Prompt 的完整文本。3.0 README 明确说明复用了相邻原创模板的基础样式、英文 MDX、依赖和 SVG；1.0 的 Legal 也是追加实现。故可以确认 3.0 产物的综合能力更强，不能把每项收益都归因于 Prompt 文本本身，也不是相同输入条件下的独立 A/B 测试。

## 推荐

长期底座采用 3.0 的共享组件、MDX 自动发现和本地化路由，补回 1.0 的 Legal 内容结构，再换成真实游戏的核实内容与图片。保留原始版作为视觉尺寸与原站结构的对照样板。无需继续在 1.0 上重复补多语言。
