## 工程验收

- `pnpm test`：8 项通过，包括文件发现、日期和元数据错误、locale 路由冲突、实际 MDX 编译属性与 JS 禁用。
- `pnpm typecheck`：通过。
- `pnpm build`：通过；15 个内容页面为 SSG，robots/sitemap 为静态产物。
- `pnpm verify:routes`：15 个动态发现页面通过，检查 HTML 语言、MDX、图片、内部链接、canonical、完整且唯一的 hreflang/x-default、robots、sitemap、404 和英文别名跳转。
- `pnpm verify:browser`：30 个页面/视口检查通过，包含图片加载、横向溢出、页面异常、站点控制台、FAQ 与菜单键盘/ARIA；五种语言的首页→列表→文章→首页键盘导航通过。
- 实际临时新增 `content/en/qa.mdx` 后，构建自动生成第 16 页，列表/首页增加入口，路由与 sitemap/hreflang 验证自动适配。测试文件已移除，最终重新构建并验证恢复为 15 页。
- `SITE_INDEXABLE=true` 的配置与 robots Allow 验证通过；最终仍保持默认 `noindex, follow`，robots 允许读取页面索引指令。
- 浏览器扩展来源错误单独保存在 `report.json` 的 `extensionErrors`，不作为站点错误；站点错误仍会使验证失败。
- 独立代码复核后修正 robots 与 noindex 配合、MDX 属性兼容及新增文章面包屑标题；复核未发现剩余阻断或重要问题。

没有部署、统计代码、额外攻略、Search 或 Legal 扩展。原目录没有这些已有应用能力；原 `.gitignore` 保留并补充本地验证产物规则。
