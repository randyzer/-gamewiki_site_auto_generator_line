# Agent V2 P5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将七个核心阶段逐步接入统一 V2 Stage Adapter、Artifact、Evidence、Approval、State、Handoff 与 Publication 接口，并完成离线全链路和回滚验收。

**Architecture:** 使用 Strangler Migration。先冻结身份、事务协调和 fixture 契约，再逐阶段增加只读 Adapter 与 Shadow 比较；生产入口、真实能力和权威切换放在独立批准之后。历史 `wallpaper-engine-002` 始终只读。

**Tech Stack:** Node.js ESM、`node:test`、JSON Schema、Canonical JSON、append-only file stores、现有 Agent V2 P1–P4 模块。

---

## 执行约束

- P5-A 至 P5-H 必须使用独立 PR，顺序合并，不并行修改同一工作区。
- 每个 PR 先增加失败测试，再最小实现，再运行聚焦测试和 `cd agent && npm test`。
- 每个准确 Head 必须经 ChatGPT 独立审查后才可创建 PR；PR 的准确 Base/Head 再经合并审核。
- P5-H 之前不修改 `agent/src/pipeline.mjs`、`agent/src/orchestrator.mjs` 或 `agent/src/skill-executor.mjs` 的生产接线。
- P5 Offline 禁止真实 Worker、网络调研、服务恢复、浏览器写操作和部署。
