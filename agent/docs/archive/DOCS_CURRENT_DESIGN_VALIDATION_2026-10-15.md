## 与任务设计描述相比需写准的实现边界

- [terminal-run](../../src/terminal-run.mjs)只检查 stdin.isTTY 与输入 y；Codex 不代输是入口约束，不是代码具备识别人类操作者的证明。保留的旧 CLI 命令意味着 run/retry 是当前新站主线入口，不能声称旧命令已删除。
- [worker-permissions](../../src/worker-permissions.mjs)只在关键词阶段和部署 execute 开放命令网络，模型客户端认证是独立边界。首页 worker 还可生成图像，不能把所有 worker 写成只读证据。
- [pipeline](../../src/pipeline.mjs)在部署 worker 调用前置 deploymentExecuted=true；执行失败也可能保留，须另看部署报告与服务证据。
- [artifact-validator](../../src/artifact-validator.mjs)的部署成功结构校验仅要求 PRODUCTION LIVE 与域名一致，不独立证明远端或每项 Google 服务成功。
- rawKeywordsFile/lineage 的宿主输入检查可接受 run 外文件，但 worker 仅为 run 内原件显式加读权限；当前主线首跑需验证这一缺口。
- 即使 execute 开放站点写入，worker 权限生成器仍将写目录下 .git 标为只读；涉及 Git 元数据写入的真实部署可行性需核验。
- plan 轮不开放命令网络，真实远端 Git 状态检查的可行性未验证；deploymentProvider 是允许字段而非 missingInputs 必填项。
- 默认 executor 使用 PATH/CODEX_BIN；二进制身份校验是显式传入身份时的可选路径。冻结模块的旧条件分支仍保留。
- [prelaunch-host](../../src/prelaunch-host.mjs)不主动请求站外链接，但页面浏览器渲染可能加载外部资源，不能声称宿主全局断网。
